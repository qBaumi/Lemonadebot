This Twitch bot has several custom features including:

  - Displaying currently playing song in the background of the Stream using the LastFM API.
  - Displaying Statistics of the recently played games including ranking.
  - When a user redeems a reward through twitch it can add a user requested song to a custom spotify playlist.
  - Tracking 7tv emotes used in a twitch chat to determing not frequently used emotes in order to free up open slots available for new emotes
  - it also included its own flask API to make its tracked data available to my different project called Lemon-Website
